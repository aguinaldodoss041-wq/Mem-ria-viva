# Mem-ria-viva
Cria um projeto de identidade visual completo para uma empresa tecnológica chamada MEMÓRIA VIVA.  Slogan: Cada pessoa tem uma história.  A empresa transforma fotografias, histórias e recordações pessoais em experiências digitais.  Cria os seguintes materiais:  1. Logótipo profissional. 2. Cartão de visita digital. 3. Ca.
